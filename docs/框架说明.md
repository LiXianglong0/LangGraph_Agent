# LangGraph Agent 框架说明

## 1. 项目定位

**LangGraph + FastAPI + Vue**，对接独立部署的 **RAGFlow** 知识库（可选）。

| 层级 | 技术 | 职责 |
|------|------|------|
| 前端 | Vue3 + Vite | 配置（模型 / RAGFlow）+ 聊天 |
| 后端 | FastAPI | HTTP API、CORS、Agent 单例 |
| 编排 | LangGraph ReAct | 模型 ↔ 工具循环 + MemorySaver |
| 知识库 | RAGFlow（Docker 独立） | 文档解析与检索；本系统仅 HTTP 调用 |

模型默认：智谱 `glm-4-flash`（OpenAI 兼容接口）。

## 2. 架构

```text
┌──────────────┐   /api/*    ┌──────────────┐         ┌─────────────────┐
│ web/ Vue     │ ──────────► │ api/ FastAPI │ ───────► │ agent/ LangGraph│
└──────────────┘             └──────┬───────┘         └────────┬────────┘
                                    │                          │
                                    │ 可选                      │ knowledge_search
                                    ▼                          ▼
                             ┌──────────────┐         ┌─────────────────┐
                             │ .env 预置    │         │ RAGFlow 独立服务 │
                             │ RAGFLOW_*    │         │ /api/v1/retrieval│
                             └──────────────┘         └─────────────────┘
```

RAGFlow **不**并进 Python 进程；可在**同一 Git 仓库**用总 compose 一起启停，运行时仍是独立容器，Agent 通过 HTTP（`knowledge_search`）调用。

## 3. 目录

```text
agent/                 # LangGraph 核心 + ragflow 客户端
api/                   # FastAPI
web/                   # Vue3
deploy/                # 统一 Docker 编排
  docker-compose.yml   # 总编排：Agent + RAGFlow
  start.sh / stop.sh
  bootstrap-ragflow.sh # 拉取 third_party/ragflow
third_party/           # bootstrap 后出现 ragflow 源码（默认 gitignore）
docs/框架说明.md
```

## 4. API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/health` | 健康检查 |
| GET | `/api/tools` | 工具列表 |
| GET | `/api/defaults` | 默认模型 + 工具 + RAGFlow 预置 |
| POST | `/api/chat` | 对话（`config.ragflow` 可随请求下发） |
| POST | `/api/ragflow/ping` | 按配置探测 RAGFlow 连通性 |

Swagger：`http://127.0.0.1:8001/docs`

## 5. 同仓总 Compose 启停（推荐 WSL）

详见 [deploy/README.md](../deploy/README.md)。

```bash
chmod +x deploy/*.sh
./deploy/bootstrap-ragflow.sh   # 克隆到 third_party/ragflow，生成 ragflow.env
./deploy/start.sh               # Agent :8001 + RAGFlow :8088
./deploy/stop.sh
```

容器内 Agent 默认访问 `http://ragflow-cpu`；浏览器访问 RAGFlow 用 `http://localhost:8088`。

前端控制台菜单：首页 / 智能对话 / 模型服务 / 知识库 / 系统（可继续扩展）。

对接步骤：

1. 总栈启动后打开 RAGFlow → 建 Dataset → 解析文档 → 创建 API Key。
2. `.env` 或「知识库」页填写 `RAGFLOW_*` / Dataset IDs，并启用。
3. 「知识库」页探测连通 → 「智能对话」页开启检索后提问。

检索：`POST {base_url}/api/v1/retrieval`。

## 6. 本地开发运行（自行执行）

```powershell
# 后端（不加 Docker 时）
pip install -r requirements.txt
python -m api.main

# 前端
cd web
npm install
npm run dev
```

## 7. 记忆

`MemorySaver` + `thread_id`：进程内短期记忆。重启后端即清空。生产可换 Postgres Checkpointer。

## 9. 常见问题

| 现象 | 处理 |
|------|------|
| 前端连不上后端 | 先起 `python -m api.main` |
| 探测 RAGFlow 失败 | 检查服务是否启动、端口、API Key、dataset_ids |
| 未检索到片段 | 文档是否解析完成；阈值是否过高 |
| 与 FastGPT 端口冲突 | 不要混用；RAGFlow 单独改 `.env` 端口 |
